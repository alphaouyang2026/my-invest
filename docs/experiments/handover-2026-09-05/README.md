## 交易回测接入所需的统一规则

以下条目当前**没有任何脚本实现**，必须在设计并获授权后另行落地。列出它们是为了说明"预测能力"到"可交易收益"之间还缺什么，不是承诺这些数值。

### 成本与滑点

- 委托手续费率与最低费用，按实际券商费率表，区分买入卖出。
- 日本市场卖出适用的税费（如有），以及任何按金额或按笔计费项。
- 滑点模型：至少区分按固定 bp 与按当日成交量比例两种口径，并说明选择依据。
- 借券成本与可借券性（若允许做空）；不允许做空时需在组合构造阶段显式约束。

### 执行假设

- 成交价基准：信号在 t 日收盘后产生，最早可执行时点是 t+1 开盘还是 t+1 收盘（VWAP 亦需明确），必须与标签定义 `close[t+h+1] / close[t+1] - 1` 保持一致，否则回测与训练目标错位。
- 单日成交量上限（占当日成交额比例），以及超限时的拆单或放弃规则。
- 涨跌停、停牌、临时停牌期间的处理；无法成交时是顺延还是放弃。
- 最小交易单位与整手约束。

### 组合构造

- 持仓数量或权重上限、行业与个股集中度约束。
- 调仓频率：20 日标签意味着信号重叠，需明确是每日调仓叠加还是按 20 日周期分批。
- 换手率约束与目标，以及换手与成本的联动。
- 现金与杠杆约束。

### 统计口径

- 收益、波动、最大回撤、换手、成本占比的统一定义与年化方式。
- 与基准（如市值加权或等权全市场）的对比口径。
- 成本前与成本后必须分别报告，不能只给成本前。

### 数据与时点

- 回测使用的股票池必须与训练一致（同一每日股票池冻结规则）。
- 退市、并购、股本变动的处理必须与 provider 的复权语义一致。
- 任何在回测中使用的数据都必须只包含决策时点可得的信息。

## 待确认：新时期盲测

本轮全部结论来自 2026-02-17～2026-04-21 的 44 个共同成熟日期，这段时期已参与开发和候选选择。要判断该候选是否真的有效，需要一段**未参与任何选择**的时期做盲测。需要确认的事项：

1. 盲测时期的起止范围，以及它必须晚于本轮全部选择行为的时点。
2. 快照是否需要扩充历史或等待新数据落库；当前快照的覆盖终点决定了可用盲测长度。
3. 盲测只运行本目录冻结的单个候选，不再做任何参数或结构比较；一旦在盲测期上比较多个候选，该时期即失去盲测性质。
4. 盲测结果的接受或拒绝标准必须在运行前冻结。
5. 是否同时接入上述交易成本规则，还是先只做预测能力的盲测。

在这些事项确认前，不应把本轮候选投入任何实盘或半实盘用途。
