# 13 — Qlib 点时基本面因子扩展

**What to build:** 用户同步财务摘要和决算发表信息后，可以在 DataSnapshot 约束下使用 Qlib `P`/`PRef` 研究至少一个价值、质量或成长因子。系统分别处理报告期、公开时间和修订版本，确保历史研究只能看到当时已公开的财务事实，并在研究页面展示覆盖率、分布和因子效果。

**Blocked by:** 06 — Qlib 数据适配与动量因子研究

**Status:** ready-for-agent

- [ ] 财务摘要和决算发表信息可同步、校验并纳入版本化事实，报告期、公开时间、来源发布时间和修订版本分别保存
- [ ] DataSnapshot 明确限制可见的财务 publication；后续修订不会改变已绑定实验的历史输入
- [ ] 为 PIT 基本面扩展独立、版本化的数据包 schema；对应 QlibDataBundle 以 `P`/`PRef` 或等价的 Qlib 点时机制按公开时间对齐报告期
- [ ] 至少实现一个价值、质量或成长因子，其定义、所需字段、缺失处理、方向和版本可查
- [ ] 研究页面可选择基本面因子并展示覆盖率、缺失率、分布、IC/Rank IC 和分组收益
- [ ] 基本面特征可加入 ResearchExperiment 的特征集，但默认不改变动量黄金基线
- [ ] 时间隔离测试覆盖尚未披露、披露日边界、同一报告期多次修订、缺失披露时间及快照冻结
- [ ] 数据质量异常以结构化原因展示，不用报告期末日期替代未知公开时间
