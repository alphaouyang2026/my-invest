# 07 — Qlib 多因子与 LightGBM 预测选股

**What to build:** 用户可以从现有价格量数据中选择适用的 Qlib Alpha158/Alpha360 特征，按时间顺序定义训练、验证和测试区间，训练一个 LightGBM 收益或排序预测基线；完成后查看样本外 PredictionRun、选股排名、特征重要性和实验指标，并与 6-1 动量基线比较。

**Blocked by:** 06 — Qlib 数据适配与动量因子研究

**Status:** ready-for-agent

- [ ] 提供经现有字段可用性验证的 Alpha158/Alpha360 特征子集；每个特征记录表达式、所需字段、窗口和版本
- [ ] ResearchExperiment 可声明特征集、未来收益标签、训练/验证/测试区间、LightGBM 参数和随机种子
- [ ] 数据切分严格按时间顺序，训练预处理只拟合训练区间；测试覆盖随机打散、标签越界和预处理泄漏不会发生
- [ ] 模型训练、验证、推理和 recorder 通过 Qlib 完成，模型产物与数据快照、特征集、标签、参数、Qlib/代码版本绑定
- [ ] PredictionRun 保存每只证券的预测时点、原始分数、标准化分数、模型运行及数据快照引用，不与 TargetPortfolio 或实际持仓混用
- [ ] 研究页面可发起训练、查看进度与失败原因，并展示样本外 IC/Rank IC、分组收益、特征重要性和证券排名
- [ ] 用户可并列查看 LightGBM 与动量基线的样本外指标；J-Quants Free 数据限制和观察点数量同时展示
- [ ] 固定小型数据集和随机种子可复现训练与预测结果，普通 CI 不依赖网络或生产数据
