# 09 — 日本市场历史模拟成交与 Decimal 账务

**What to build:** 用户将某个历史决策日的 TargetPortfolio 提交给模拟账户后，系统在下一实际交易日按当时的行情与日本市场规则生成模拟订单和成交，并以 Decimal 更新现金、待结算现金、持仓、费用和净值。页面展示这次调仓为何成交、部分成交、拒绝或过期；这些本地结果是正式模拟账务，Qlib float 账户结果仅作研究参照。

**Blocked by:** 08 — Qlib 目标组合与日本市场风险预览

**Status:** ready-for-agent

- [ ] 信号时间、下单时间和成交时间严格分离，默认在决策日后的下一实际交易日开盘模拟成交，不使用已经结束的决策 K 线成交
- [ ] 订单数量执行 100 股整手、可用现金和最小调仓金额约束；成交执行价格精度、停牌、値幅制限、无成交量和成交量参与率规则
- [ ] 支持零成本、基准成本、压力成本和自定义成本场景，显式费用与滑点分别计算并展示
- [ ] SimOrder 状态支持 CREATED、FILLED、PARTIALLY_FILLED、REJECTED 和 EXPIRED，状态变化及原因可追溯
- [ ] 订单、成交、数量、现金、待结算现金、费用、成本、持仓市值和净值使用定点数保存；因子和预测浮点数不会进入最终账务字段
- [ ] 默认现金模式允许卖出所得用于同日调仓；严格结算模式按 TradingCalendar 的开放交易日维护待结算现金
- [ ] 模拟账户页面展示单次调仓的目标、订单、成交、未成交原因、现金、持仓和净值变化
- [ ] 属性测试验证账务恒等式、舍入、部分成交、费用边界和两种结算模式；固定日本市场案例验证整手与値幅制限
