# 08 — 成交模型与模拟成交

**What to build:** 给定通过风险检查的目标权重，生成模拟订单并按成交模型产生模拟成交结果；以集中配置管理价格精度、市场最小交易单位、固定单边滑点（默认 10bp）、成交量参与率上限、手续费税费和最低费用、停牌/涨跌停/无成交量限制，默认按次日开盘价成交，并处理部分成交与未成交过期。订单状态遵循 CREATED→FILLED/PARTIALLY_FILLED/REJECTED/EXPIRED；同时支持零成本/基准成本/压力成本/自定义四种成本场景，结果分别展示毛收益、显式成本、滑点损失。

**Blocked by:** 07 — 组合构建与模拟交易前风险检查

**Status:** ready-for-agent

- [ ] 目标权重生成模拟订单，成交价默认使用次日开盘价（不得使用信号生成时已结束的同根 K 线价格）
- [ ] 当前 Prime Market 的价格精度、最小交易单位、停牌及涨跌停规则可查询并集中配置，不硬编码并散落在成交逻辑中
- [ ] 滑点、手续费、税费、最低费用按配置计算，且与成交量参与率、涨跌停、停牌、无成交量限制联动
- [ ] 单元测试覆盖市场规则和成本配置的读取
- [ ] SimOrder 状态机 CREATED→FILLED/PARTIALLY_FILLED/REJECTED/EXPIRED 由回测引擎和成交模型驱动
- [ ] 零成本、基准成本、压力成本（默认基准两倍）、自定义四种场景均可运行并展示毛收益/显式成本/滑点损失/净收益
- [ ] 属性测试覆盖数值边界（如成交量参与率上限、涨跌停边界）
