# 14 — 量化研究仪表盘、设置与结果导出

**What to build:** 用户从仪表盘可以了解数据快照、QlibDataBundle、近期 ResearchExperiment、模型、PredictionRun、TargetPortfolio、回测和模拟账户状态，并导出带完整版本身份的 CSV 或报告。设置页面只开放前序能力已经声明为可配置的市场、成本、研究和数据源选项，所有界面明确区分研究近似结果与历史模拟账务。

**Blocked by:** 11 — Qlib Portfolio 分析与策略比较

**Status:** ready-for-agent

- [ ] 仪表盘展示数据/快照状态、QlibDataBundle 状态、近期实验和模型任务、近期回测以及模拟组合关键指标
- [ ] 实验、预测、目标组合和回测之间可导航，用户能够从结果追溯数据快照、特征、标签、模型、策略和版本
- [ ] Qlib ResearchBacktest、PredictionRun、TargetPortfolio、ExecutionReplay 和模拟账户使用清晰且不同的标签
- [ ] 设置页面可查看和编辑前序 ticket 已声明为用户可配置的市场规则、成本场景、研究参数及数据源状态；密钥只展示配置说明和连接状态
- [ ] 导出支持实验指标、证券预测、目标组合、成交账务和绩效比较，文件包含数据/模型/策略/代码版本及限制说明
- [ ] CSV 和报告只写入配置允许的目录，文件名和用户输入不能逃逸该目录
- [ ] 所有结果页面和导出物明确标识为历史研究或模拟交易，不表现为真实账户、真实成交或投资保证
- [ ] 端到端测试覆盖仪表盘导航、设置生效、导出内容、路径限制和研究/账务标签
