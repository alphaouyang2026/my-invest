# 03 — J-Quants 主数据与日线同步

**What to build:** 后端可按需触发同步任务，从 J-Quants API V2 Free 导入 Prime 普通股上市标的主数据和全日日线，正确处理分页、每分钟 5 次限流、HTTP 429 重试与指数退避；密钥通过环境变量或本地密钥文件配置，不写入源码/数据库日志/导出结果；数据中心页面展示同步状态与数据覆盖范围（含实测的最早/最晚日期，不硬编码"两年"边界）。

**Blocked by:** 02 — 市场规则配置与可替换交易日历接口

**Status:** ready-for-agent

- [ ] 触发同步任务后可导入 Prime Market 普通股主数据和历史日线到 PostgreSQL
- [ ] 分页、限流（5 calls/min）、HTTP 429 重试与指数退避有测试覆盖（数据适配测试）
- [ ] J-Quants API key 通过环境变量或本地密钥文件配置；日志与导出结果中不包含密钥
- [ ] 每次同步记录每个端点实际返回的最早和最晚日期
- [ ] 数据中心页面展示最近同步状态、数据覆盖范围和导入任务列表
- [ ] 同步失败的批次不会污染已有数据，错误原因可查
